# 行动项按负责人汇总

## 目标

提供可复用的行动项汇总功能，输入包含行动项的JSON数据，直接输出按负责人整理后的统计结果

## 工作流

1. 接收包含items数组的JSON输入，每个item包含owner、task、done三个字段
2. 按负责人owner对行动项进行分组
3. 统计每个负责人的总任务数量、已完成任务数量
4. 收集每个负责人的所有未完成任务列表
5. 返回汇总后的结构化JSON结果

## 使用边界

- 只使用宿主本轮明确提供的工具和上下文，不假定未声明的能力。
- 涉及外部发送、安装、删除、覆盖或其他副作用时，先遵守宿主确认策略。
- 只有工具返回可验证成功结果后，才能声称动作已经完成。
- 依赖缺失或结果无法验证时明确说明，不用默认值或假成功掩盖失败。

以下脚本只能通过 Skill 工坊的 `run_skill_script` 工具运行。先加载 `skill-creator`，再传入当前 Skill 名、脚本名和 JSON 输入；不要用 shell、Python 或其他方式绕开沙箱直接执行。
