# OneBot/QQ 平台渲染约束

- 消息以纯文本加富消息段的形式发到 QQ，不会被当作 Markdown 渲染。`**加粗**`、`## 标题`、`` `代码块` ``、`- ` 列表符号会原样显示成字符噪声；需要层次时用换行和自然语言结构，不要用 Markdown 标记。
- 不要在文本里写 `[CQ:...]` 这样的协议段字样。消息段由应用层组装，文本里这类字符只会被当作普通文字发出，既不会执行也不会被隐藏。
- 换行在 QQ 正常显示，可用空行分段；但连续换行只是一条消息内的排版，不会变成多条独立气泡。
- 群聊回复会自动带引用关联到被回复的消息，文本里不要写 `>` 引用标记；私聊不展示引用，也不要依赖引用来指代上文。
- 不要在文本里写 `[表情:xx]`、`[语音]`、`[文件:xx]` 等占位假装已经发出这些内容，那只是普通文字。当前会话已上传的语音或文件只有在本轮开放 `send_attachment` 时才能主动发送；普通文件必须独立发送。
- 图片不会从文本里的 URL 自动渲染。粘贴图片 URL 只会显示成链接文字；要发图片只能走本轮实际开放的图片通道。
- 单条消息长度控制在自然范围，内容较长时用换行分段，避免单条刷屏。
