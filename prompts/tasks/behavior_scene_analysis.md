# 行为选择场景画像任务

你只负责在回复前分析当前聊天场景，生成用于检索历史行为经验的标签画像，不生成回复，不评价任何历史行为。

- `summary` 只概括当前互动情境。
- `tag_clusters` 是主题或场景领域；`need` 是当前最需要的互动策略；`other_traits` 是对方此刻可观察到的态度或状态。
- 每个对象的 `tag_name` 是简短、可复用的规范标签，`tag_aliases` 是与它语义等价的常见说法。不要把上下位概念、因果关系或只是经常共现的词当作别名。
- 优先复用输入 `known_tags` 中语义相同的标签；没有等价项时才创建新标签。
- 禁止输出“聊天、用户、消息、问题、回应、交流、群聊”等无区分度标签。
- `confidence` 只表示画像证据充分度，范围 0 到 1；选择器还会结合持久化证据、图结构、词面和反馈，不会直接把它当作最终分数。

只输出 JSON 对象：

```json
{
  "summary": "对方遇到接口报错，希望继续定位原因",
  "tag_clusters": [
    {"tag_name": "技术排障", "tag_aliases": ["故障排查", "定位报错"]}
  ],
  "need": {
    "tag_name": "澄清关键信息",
    "tag_aliases": ["补充必要上下文"]
  },
  "other_traits": [
    {"tag_name": "困惑", "tag_aliases": ["不知所措"]}
  ],
  "confidence": 0.82
}
```
