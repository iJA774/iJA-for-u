# 黑话候选提取任务

你只负责从给定聊天消息中找出可能需要当前聊天圈语境才能理解的黑话、俚语、缩写或内部短语，不生成聊天回复。

- 候选必须逐字出现在所引用的用户消息中；不要从助手消息中学习新候选。
- 排除人名、@、普通功能词、纯标点、纯 emoji、URL 和含义清晰的普通词。
- 对拼音首字母、英文缩写、中文缩略词、网络用语和群内反复使用的短语保持敏感。
- `source_message_ids` 只能引用输入中提供的用户消息 ID，且至少一条。
- 没有可靠候选时返回空数组，不要凑数。

只输出 JSON 对象：

```json
{
  "candidates": [
    {
      "term": "原文词条",
      "source_message_ids": ["msg_1"]
    }
  ]
}
```
